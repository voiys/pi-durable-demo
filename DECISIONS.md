# Decisions

- 2026-10-18 · Tools pinned with mise (`mise.toml`): node 24.20.0, pnpm 12.6.0 (the versions already installed and working on this machine). Asked for by the user.
- 2026-10-18 · No Cloudflare login for v0: alchemy v2 local dev falls back to a dummy account id when none is configured (`alchemy-v2-beta83: packages/alchemy/src/Cloudflare/LocalAccount.ts`), and nothing in v0 needs a remote resource.
- 2026-10-18 · Auth model (user's call): users sign in with email/password (better-auth). "Sign in with ChatGPT" is a separate *connect your ChatGPT plan* step, and pi runs on that plan's token. One ChatGPT account may be connected to several app users for the demo. No backup model: a user with no connected plan can't chat, and the app says so.
- 2026-10-18 · SIWC terms (https://openai.com/policies/sign-in-with-chatgpt-terms/, dated 2026-09-29) limit the demo: tokens may only be stored "local and under the user's control", requests must come from the user's own runtime, and "using one user's subscription to fulfill another user's requests" is banned. So: the app stays local-only (workerd on this machine). One ChatGPT plan connected to several app users is OK only because every one of those test users is the same person (the owner). It must never be used by other people, and the app is not deployed with SIWC.
- 2026-10-18 · OptChat is the default (and only) chat structure: every chat's main agent runs on the OptChat memory (user's call: "we should use optchat as our default chat structure"). The per-chat "OptChat" button and `optchat` kv flag go away. Subagents keep plain pi context.
- 2026-10-18 · Model picker offers only GPT-6.1 Sol, GPT-6 Astra and GPT-6 Luna (user's pick), filtered by what the ChatGPT plan lists.
- 2026-10-18 · OptChat memory is per user (User DO), shared by every chat; log entries carry the chat id in metadata; the `[chat "<title>"]` label is added only where a model reads the text (compactor source, zoom), never stored (user's call). Old per-chat memories were dropped, not migrated (local dev data). Deleting a chat keeps its lines in the memory: the log is append-only by design.
- 2026-10-18 · OptChat fix plan (research/optchat-fix-plan.md) applied: pi compaction is declined for root conversations (OptChat owns history, upstream index.ts:475); each chat's memory cursor (last logged entry id) lives in the User DO; logging happens at run start (settled, then input), after each tool round and at the answer; one view per run (memo); the summarizer is gpt-6-luna at low effort, 3 at a time, 90 s timeout, and it fails loudly if the plan lacks it.
